# snowflake-platform-airflow3

Runs `contoso-data-product` on **snowflake-emulator (or a real Snowflake account) orchestrated by an external Apache Airflow 3** — the Snowflake counterpart of [`fabric-platform-airflow3`](https://github.com/calvinchengx/fabric-platform-airflow3).

Distinct from [`snowflake-platform-tasks`](https://github.com/calvinchengx/snowflake-platform-tasks), which drives the same product through Snowflake's own Tasks. Same product, two orchestrators.

The platform installs the product and knows no Contoso.
